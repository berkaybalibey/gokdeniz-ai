Gökdeniz AI

Yerel yapay zekâ modelleriyle çalışan, Streamlit tabanlı bir asistan uygulaması.

Özellikler

Belge Asistanı: PDF, TXT ve Markdown dosyalarından bilgi bulma ve soruları yanıtlama.

Genel Asistan: Yerel yapay zekâ modeliyle soru-cevap.

Hesap Makinesi: Temel matematiksel işlemleri doğrudan hesaplama.

Kullanılan Teknolojiler

Python

Streamlit

Foundry Local

PyPDF

Kurulum

Python 3.12 kurun.

Proje klasöründe sanal ortam oluşturup etkinleştirin.

Gerekli paketleri yükleyin:

pip install -r requirements.txt

Foundry Local ortamını kurup gerekli modelleri indirin.

Uygulamayı başlatın:

streamlit run app.py
